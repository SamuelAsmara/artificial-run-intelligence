demo dataset, six documents as Word, and a pace column that held a duration

Adds scripts/seed-demo.ts: one coach, twenty athletes across four race
groups, sixteen weeks of history each and a full plan to race day. The
script writes only raw inputs — distance, duration, heart rate, sleep —
and imports the application's own modules (recomputeForUser,
readCapacity, estimateThresholds, generatePlan) for everything derived.
A demo built from hand-tuned CTL values proves nothing; this one is a
live test of the engine over twenty athletes at once.

It found two real defects on its first dry run.

plan_workouts.planned_pace is declared `interval` and every writer puts a
pace label in it. Postgres reads "5:49" as five hours forty-nine minutes,
and every reader treats the column as an already-formatted string. No row
had ever been written to it — no plan had ever been generated against a
real account — so nobody had seen it. Migration 0016 changes the column
to text, which is what the value has always been.

The second is not fixed here and needs a decision. When an athlete has no
sustained hard effort of 35–75 minutes, estimateThresholdSpeed falls back
to the fastest run over twenty minutes and shades it down 6%. For a
low-volume runner that run is an easy long run, so the estimator treats an
easy pace as threshold and then slows it further: prescribed easy paces of
8:15 to 10:29 per kilometre for athletes who actually run 6:45. The seed
works around it with a minutes-based floor on generated sessions; the
underlying fallback is still wrong for real users.

Also converts the six course documents from the markdown drafts to Word
with full RTL, tables, code blocks and page furniture (scripts/md2docx.js,
so they can be rebuilt after any edit to the source). The previous .docx
versions moved to _archive/ rather than being deleted.

Adds the first structure of the presentation — fourteen slides in the
product's own palette, with speaker notes. Slides 5–7 carry placeholder
frames until the demo data is in and the screenshots can be taken.
