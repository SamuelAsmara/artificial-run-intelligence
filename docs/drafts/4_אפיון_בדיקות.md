## מה נבדק, ולמה דווקא כך

**ולמה זה חשוב:** בדיקה שרצה ב-14 שניות רצה **לפני כל שינוי**. בדיקה שדורשת
מסד ודפדפן רצה פעם ביום, ואז מפסיקים להריץ אותה.

### מה בכוונה לא נבדק אוטומטית

**רינדור קומפוננטות ו-E2E בדפדפן.** תוכננו React Testing Library ו-Playwright
ולא מומשו. **הסיבה כנה:** התקציב הוגבל, והיה צריך לבחור בין לבדוק שכפתור
מרונדר לבין לבדוק שהחישוב מאחוריו נכון.

**בחרנו בחישוב** — כי באג בכפתור נראה בעין, ובאג בנוסחת העומס לא. ריצה
שנרשמה כשיא איטי יותר משהייתה היא באג שאף אחד לא רואה, וזה בדיוק סוג הבאג
שבדיקה תופסת.

**במקום זאת בוצעה סריקה ידנית מתועדת** מקצה לקצה — ראו סעיף 8. המטלה מאשרת

## 4. בדיקות הרשאות

**נבדקו ידנית מול המסד**, לא אוטומטית — אין פרויקט בדיקות נפרד.

| מה נבדק | תוצאה |
|---|---|
| מדיניות יצירת קשר מאמן־מתאמן | **נמצאה פרצה.** ראו סעיף 8 ומסמך האבטחה |
| אתלט מנסה להגיע ל-`/coach` | חסום ב-layout אחד לכל הענף |
| מאמן עורך אימון של מתאמן | מותר, ונבדק שהכתיבה באמת קרתה |
| מאמן עורך אימון של מי שאינו שלו | נחסם |
| עזיבת מאמן ע"י המתאמן | **היה שבור** — דיווח הצלחה והתאים אפס שורות |

**זה הלקח המרכזי בסעיף הזה:** פוסטגרס לא זורק כשמדיניות מסרבת — הוא לא
מתאים שורות והפעולה מדווחת הצלחה. **בדיקה שרק בודקת "לא הייתה שגיאה" תעבור
על קוד שבור.** לכן כל כתיבה רגישה מבקשת בחזרה את השורות שהשתנו.

## 5. בדיקות למסד הנתונים

| מה | איך אומת |
|---|---|
| ייחודיות ריצה לפי מקור ומזהה חיצוני | ייבוא חוזר לא מכפיל |
| ייחודיות תמונת מצב לפי `(משתמש, תאריך)` | כתיבה חוזרת מעדכנת |
| מדיניות ההרשאות | שאילתה ישירה ל-`pg_policy` |
| קיום כל עמודה שנוספה | `information_schema.columns` |
| אילוץ `origin` | `pg_constraint` |
| האינדקסים | `pg_indexes` |

**כלל שנקבע אחרי שנכווינו:** מיגרציה מאומתת מול `information_schema`
ו-`pg_policy` — **לא מול הודעת ההצלחה**. מיגרציה דווחה כמוצלחת ולא רצה,
והתגלה רק כשפיצ'ר שלם לא עבד.

## 9. מגבלות ומה היה נבדק בהמשך

| מגבלה | מה היה נדרש |
|---|---|
| אין בדיקות רינדור | React Testing Library לקומפוננטות המורכבות |
| אין E2E בדפדפן | Playwright לתהליכי ההרשמה, החיבור והתוכנית |
| הרשאות נבדקות ידנית | פרויקט Supabase לבדיקות ו-client לכל תפקיד |

| אין בדיקות עומס | k6 או Artillery מול הפריסה |

**המגבלה שהכי מטרידה אותי היא השלישית.** ההרשאות הן החלק שבו טעות עולה
הכי ביוקר — וזה בדיוק החלק שנבדק בעיניים. הפרצה שנמצאה מוכיחה גם שהבדיקה
הידנית עבדה, וגם שהיא הגיעה מאוחר.
